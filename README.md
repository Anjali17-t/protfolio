# Personal Portfolio Website

## About

This is my personal portfolio website, created to showcase my **skills, education, projects, and career interests** as a B.Tech Information Technology student.

The portfolio provides a simple and responsive way for recruiters and internship opportunities to learn about my technical background and projects.

## Features

* Responsive navigation bar
* Home section with personal introduction
* Skills section
* Education details
* Projects showcase
* Project details with interactive components
* Contact section
* Responsive design for different screen sizes
* Clean and user-friendly interface

## Technologies Used

* HTML5
* CSS3
* Bootstrap 4.5.2
* Font Awesome
* JavaScript

## Projects Featured

### FaceNet Based Attendance System

A facial-recognition-based attendance system developed using Python, DeepFace, FaceNet, and OpenCV to automate attendance using facial recognition.

### Facial Emotion Recognition

A CNN-based project focused on recognizing facial emotions and exploring its application in adaptive learning environments.
